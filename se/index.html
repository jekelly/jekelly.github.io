Edge search shortcuts

Add these providers to Microsoft Edge. To search, type a shortcut such as ddc in the address bar, press Tab, then enter your search.

Install

Open PowerShell as administrator and paste this command. Confirm the installation when prompted.

irm 'https://www.jkly.me/se/Install-EdgeSearchEngines.ps1' | iex

Bootstrap · Installer · Provider list

Fully exit and restart Edge afterward. Check edge://policy for ManagedSearchEngines and edge://settings/searchEngines for your shortcuts.

Remove

Keep the downloaded files together and unchanged. In the saved folder, run the following, then fully exit and restart Edge:

.\Manage-EdgeSearchEngines.ps1 -Action Remove -Confirm

This removes the policy recommendation; Edge may retain search entries or your default preference.
